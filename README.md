This repository contains a nonredundant synthesis paper for the Tau Core
temporalization program. It composes the results of Foundation Papers I--VII
with the later seed--base morphogenesis, EOCC actuality, stabilization-front,
observer-record and identifiability audits. Component theorems remain owned by
their original papers or canonical theory packets; this manuscript owns their

The synthesis now incorporates the joint-source compression without repeating
its proof. The former separator subquestions are closed as independent

## Does not claim

The paper does not claim that old-bare Tau entails EOCC, that Nature selects
the enriched temporal completion, that an absolute parent clock exists, that
observer time equals proto-time, or that Tau Core is empirically validated.
It does not derive SI time or energy units, dark matter, dark energy, GR, the
Standard Model, or a signal in JWST, CMB, weak-time, photonic, atomic, galaxy
or process-tomography data. It does not derive the thermodynamic second law,
a low-entropy boundary or a solution of the Past Hypothesis from observer
existence, action descent or stable records alone. It does not infer Parent
front rate from an observer clock without independent quantizer and
transmission calibration, nor from many clocks without an independent Parent
scale/reference.

Requirements: Python 3, `tectonic`, and the packages in `requirements.txt`.

```bash
python scripts/reproduce.py
```

The command regenerates the figures and derived audit, compiles the PDF,
builds the source-only arXiv ZIP, and runs the public tests.
